# Handoff: ออมมือ (Aommeu) — แอปบันทึกรายรับรายจ่ายสร้างวินัยการเงิน

## Overview
**ออมมือ** เป็นแอปบันทึกรายรับ-รายจ่ายบนมือถือ เป้าหมายหลักคือ **สร้างวินัยทางการเงิน** ไม่ใช่แค่บันทึกตัวเลข กลไกที่ทำให้ต่างจากแอปทั่วไป:

- **งบใช้จ่ายต่อวัน (daily envelope)** — แสดงเป็นวงแหวน "ใช้ได้วันนี้ ฿X" เป็นตัวเลขหลักของหน้าแรก
- **ฉุกคิดก่อนจ่าย (think-before-buy)** — ก่อนยืนยันรายจ่าย แอปถามเหตุผล/อารมณ์ ถ้าเป็นการซื้อตามอารมณ์ ("แค่อยากได้", "อารมณ์/ความเครียด", "เห็นโปร") จะเด้งเตือนให้หยุดคิด 24 ชม.
- **Streak** — บันทึกครบทุกวันได้ต่อเนื่อง สร้างนิสัย
- **เป้าหมายเก็บเงิน** — ตั้งเป้า ออมเพิ่มทีละก้อน เห็น % ความคืบหน้า
- **รางวัล/Badge + ชาเลนจ์ No-spend** — gamify การมีวินัย

กลุ่มผู้ใช้: คนไทยที่อยากเลิกใช้เงินเกินตัว · สกุลเงินบาท · ภาษาไทยทั้งหมด

## About the Design Files
ไฟล์ในชุดนี้คือ **ดีไซน์อ้างอิงที่สร้างด้วย HTML** — เป็น prototype ที่ทำงานได้จริง (กดเล่นได้ บันทึกข้อมูลลง localStorage จริง) เพื่อแสดง "หน้าตาและพฤติกรรมที่ตั้งใจไว้" **ไม่ใช่โค้ดโปรดักชันที่ก๊อปไปใช้ตรงๆ**

งานของผู้พัฒนาคือ **สร้างดีไซน์เหล่านี้ขึ้นใหม่ในสภาพแวดล้อมจริงของโปรเจกต์เป้าหมาย** โดยใช้แพตเทิร์น/ไลบรารีที่มีอยู่:
- ถ้าจะทำเป็น **PWA จริงจัง** → React/Vue/Svelte + IndexedDB/localStorage + service worker
- ถ้าจะทำเป็น **แอปเนทีฟ** (ขึ้น App Store / Play Store) → React Native หรือ Flutter
- ถ้ายังไม่มีโค้ดเบส → เลือกเฟรมเวิร์กที่เหมาะสมแล้ว implement ตามดีไซน์นี้

ตรรกะการคำนวณทั้งหมด (งบรายวัน, streak, สถิติ, breakdown หมวดหมู่) อยู่ใน logic class ของ `ออมมือ.dc.html` — อ่านเป็นสเปกอ้างอิงได้เลย

## Fidelity
**High-fidelity (hifi)** — สีจริง, ฟอนต์จริง, ระยะ spacing จริง, อินเทอแร็กชันครบ ผู้พัฒนาควรสร้าง UI ให้ตรงตามนี้ (pixel-accurate) โดยใช้ไลบรารีของโค้ดเบสตัวเอง ดีไซน์โทเคนทั้งหมดอยู่ในหัวข้อ Design Tokens ด้านล่าง

## ⚠️ สิ่งที่ต้องเปลี่ยนก่อนขึ้นโปรดักชัน
1. **ไม่มี status bar ปลอม** — ดีไซน์นี้ถอดเวลา/แบต/สัญญาณ/ติ่งหน้าจอออกแล้วโดยตั้งใจ เพราะของจริงมาจาก OS ใช้ `env(safe-area-inset-*)` รองรับรอยบากแล้ว ห้ามเติม status bar ปลอมกลับเข้าไป
2. **ข้อมูลเก็บใน localStorage เครื่องเดียว** — ไม่มี backend/ซิงค์/ล็อกอิน ถ้าต้องการหลายเครื่องต้องเพิ่ม backend + auth
3. **ฟอนต์โหลดจาก Google Fonts CDN** — โปรดักชันควร self-host
4. **ชื่อผู้ใช้/โปรไฟล์เป็นค่าคงที่** ("บัญชีของฉัน") — ต่อกับระบบบัญชีจริงถ้ามี

## Screens / Views

แอปมี **6 หน้าจอ** + แท็บบาร์ล่าง (5 ช่อง: หน้าแรก · สถิติ · [ปุ่ม + กลาง] · เป้าหมาย · โปรไฟล์) แท็บบาร์ซ่อนเฉพาะตอนอยู่หน้า "เพิ่มรายการ"

โครงคอนเทนเนอร์: `max-width: 440px` กึ่งกลางจอ, สูงเต็ม `100dvh`, พื้นที่เลื่อนซ่อน scrollbar, `padding-top: env(safe-area-inset-top)` และแท็บบาร์เผื่อ `env(safe-area-inset-bottom)`

### 1. หน้าแรก (Home)
- **Purpose**: เห็นงบที่ใช้ได้วันนี้ในพริบตา + ความคืบหน้าวินัย
- **Layout**: คอลัมน์เดียว padding 14/22px ด้านบน — header (ทักทาย+วันที่ ซ้าย, ปุ่มสลับธีม ขวา) → วงแหวนงบกลางจอ → แถบ streak → การ์ดเป้าหมาย → รายการล่าสุด
- **Components**:
  - **Header**: ทักทายตามเวลา ("สวัสดีตอนเช้า/บ่าย/เย็น/ค่ำ") 14px สี `--mute`; วันที่ 20px/600 สี `--text`. ปุ่มธีม วงกลม 40px พื้น `--surface` ขอบ `--border` ไอคอน sun/moon
  - **วงแหวนงบ (ring)**: SVG 236×236, วงนอก track `--ringTrack` หนา 15, วงคืบหน้า `--accent` (หรือ `--warm` เมื่อเกินงบ) `stroke-linecap:round`, `stroke-dasharray:628.3`, หมุน -90°, transition 0.5s. กลางวง: ป้าย "ใช้ได้วันนี้" 13px → ตัวเลข `฿X` 54px/600 (สัญลักษณ์ ฿ ขนาด .7em เว้น margin-right .18em) → ป้ายย่อย "ใช้ไป ฿X จาก ฿X" 13px (เปลี่ยนเป็น "เกินงบวันนี้ ฿X" สี warm เมื่อเกิน)
  - **แถบ streak**: การ์ด `--surface` radius 18px padding 14/16px, ไอคอนเปลวไฟ fill `--warm` + "บันทึกต่อเนื่อง N วัน" (N สี warm/700); ขวา 7 แท่ง (8×20px radius 4) เต็มสี warm = จำนวนวัน (สูงสุด 7) ที่เหลือสี `--track`. กดได้ → ไปหน้าโปรไฟล์
  - **การ์ดเป้าหมาย**: แสดงเป้าหมายแรก — ชื่อ + % (สี accent), progress bar 8px, ข้อความ "฿cur จาก ฿target · เหลืออีก ฿left". กดได้ → หน้าเป้าหมาย
  - **รายการล่าสุด**: หัวข้อ + ลิงก์ "ดูทั้งหมด ›"; แถวละ ไอคอนหมวด (42px radius 13 สีหมวด ตัวอักษรย่อสีขาว) + ชื่อหมวด/เวลา + จำนวนเงิน (รายรับ +สีเขียว `#8BC97E`/accent, รายจ่าย สี text). ถ้าไม่มีรายการ → empty state การ์ดเส้นประ
- **Empty state**: "ยังไม่มีรายการ / แตะปุ่ม + ด้านล่างเพื่อบันทึกรายการแรก"

### 2. เพิ่มรายการ (Add) — 3 สเตป, เต็มจอ ไม่มีแท็บบาร์
- **Purpose**: ใส่ตัวเลขเร็ว + จังหวะฉุกคิดก่อนจ่าย
- **Step 1 — จำนวน + หมวด + แป้นพิมพ์**:
  - Header: ปุ่มกากบาท (ปิด) ซ้าย, "เพิ่มรายการ" กลาง
  - Toggle รายจ่าย/รายรับ: segmented control พื้น `--surface`, ตัวที่เลือกพื้น `--accent` ตัวอักษร `--onAccent`
  - จำนวนเงิน: "฿0" กลางจอ 58px/600
  - หมวดหมู่ (เฉพาะรายจ่าย): แถวเลื่อนแนวนอน 8 หมวด, ไอคอน 50px radius 16 สีหมวด, ตัวที่เลือกมี `box-shadow:0 0 0 2px --accent`
  - แป้นตัวเลข: grid 3 คอลัมน์ ปุ่มสูง 58px ฟอนต์ Space Grotesk 26px (1-9, จุดทศนิยม, 0, ⌫); จำกัด 7 หลัก
  - ปุ่มหลัก: รายจ่าย→"ฉุกคิดก่อนจ่าย ›", รายรับ→"บันทึกรายรับ" (disabled สีจาง `--track` จนกว่าจะกรอกครบ)
- **Step 2 — ฉุกคิดก่อนจ่าย** (เฉพาะรายจ่าย):
  - แสดงยอด + หมวดที่เลือก
  - หัวข้อ "ก่อนจ่าย ลองถามใจตัวเองดู" / "นี่คือเหตุผลที่อยากจ่ายเงินก้อนนี้?"
  - 5 ตัวเลือกเหตุผล (การ์ดเลือกได้ ขอบ active = accent):
    - จำเป็นจริงๆ / วางแผนไว้แล้ว → **ไม่ใช่** impulse
    - แค่อยากได้ / อารมณ์-ความเครียด / เห็นโปร-ลดราคา → **impulse** (เด้ง nudge)
  - **Nudge** (เมื่อเลือก impulse): กล่องสี warm จาง "ลองหยุดคิดสัก 24 ชม.?" + คำอธิบาย
  - ปุ่ม "ยืนยันบันทึก" (disabled จนเลือกเหตุผล)
- **Step 3 — สำเร็จ**: วงกลม accent + เครื่องหมายถูก, "บันทึกแล้ว!", ยอดเงิน, ข้อความให้กำลังใจ (อ้าง streak), ชิป streak, ปุ่ม "เสร็จสิ้น"

### 3. ประวัติรายการ (History)
- **Layout**: header ปุ่มย้อนกลับ + "ประวัติรายการ"; รายการ **จัดกลุ่มตามวัน** (วันนี้/เมื่อวาน/วันที่ไทย) แต่ละกลุ่มมียอดสุทธิมุมขวา, การ์ด `--surface` รวมแถวรายการ
- แต่ละแถว: ไอคอนหมวด + ชื่อ/เวลา + จำนวน + **ปุ่มถังขยะ** (ลบได้จริง)
- Empty state: "ยังไม่มีประวัติ"

### 4. สถิติ (Stats)
- **การ์ดสรุปเดือน**: "ใช้จ่ายเดือนนี้ ฿X / ฿budget" + progress + "ใช้ไป X% ของงบเดือน" + เหลือ/เกิน (งบเดือน = งบรายวัน × จำนวนวันในเดือน)
- **กราฟแท่ง 7 วัน**: แท่งต่อวัน สูงตามสัดส่วน max, วันนี้สี accent วันอื่นสีจาง, ป้ายวันไทย (อา จ อ พ พฤ ศ ส)
- **Breakdown หมวดหมู่**: top 5 หมวด เรียงมาก→น้อย, จุดสี + ชื่อ + ฿ + %, progress bar สีหมวด
- Empty state เมื่อไม่มีข้อมูล

### 5. เป้าหมายเก็บเงิน (Goals)
- **การ์ดรวม** (พื้น accent): "ออมไปแล้วทั้งหมด ฿X จาก N เป้าหมาย"
- แต่ละเป้า: วงแหวนเล็ก 74px แสดง % + ชื่อ + "฿saved / ฿target" + หมายเหตุ + ปุ่ม **"+ ออมเพิ่ม ฿500"** (กดเพิ่มเงินออมจริง, ไม่เกิน target)

### 6. โปรไฟล์ (Profile)
- Header "โปรไฟล์" + ชิปสลับธีม
- การ์ดผู้ใช้: avatar + "บัญชีของฉัน" + ระดับ ("นักออมมือใหม่/เงิน/ทอง" ตามยอดออมรวม)
- **3 สถิติ**: วันติดต่อกัน (streak) · ออมสะสม · วันไม่จ่าย
- **ตั้งงบรายวัน**: ปุ่ม −/+ ปรับทีละ ฿50 (ขั้นต่ำ ฿50) — มีผลต่อวงแหวนหน้าแรกและสถิติทันที
- **ชาเลนจ์** No-spend Weekend
- **รางวัล**: grid 6 badge (ได้แล้ว=สีเต็ม, ยังไม่ได้=จาง) ปลดล็อกตามเงื่อนไขจริง (streak≥7, มีรายการ, no-spend≥3, streak≥30, ออมครบเป้า, ออม≥100k)
- **ปุ่มจัดการข้อมูล**: "ใส่ข้อมูลตัวอย่าง" / "ล้างข้อมูลทั้งหมด" (มี confirm)
- หมายเหตุท้าย: "ข้อมูลถูกเก็บไว้ในเครื่องของคุณเท่านั้น"

## Interactions & Behavior
- **นำทาง**: state เดียว `screen` สลับหน้า ไม่มี routing แยก; แท็บบาร์ + ปุ่มย้อนกลับในแต่ละหน้า
- **ปุ่ม +/FAB กลางแท็บบาร์**: วงกลม 60px สี accent ยกขึ้น -12px เงา accent → เปิดหน้า Add (รีเซ็ตฟอร์ม)
- **`.press`**: ทุกองค์ประกอบกดได้ มี `transform:scale(.97)` ตอน active (transition .12s)
- **`.key`**: ปุ่มแป้นพิมพ์ active เปลี่ยนพื้นเป็น `--track`
- **วงแหวน**: `stroke-dashoffset` transition .5s ease
- **สลับธีม**: toggle dark ↔ sage ทันที (เก็บใน localStorage แยก key)
- **ไม่มี CSS animation/keyframes** — เคยมี fade-in แต่ถอดออกเพราะ re-render บ่อยทำให้กระพริบ ใช้แค่ transition

## State Management
ทั้งหมดอยู่ใน React-style class component เดียว (`renderVals()` แปลง state→view):
- **UI state** (ไม่ persist): `theme`, `screen`, `addStep`, `amount`, `txType`, `category`, `reason`, `savedAmt`
- **Data state** (persist ลง localStorage key `aommeu_v1`):
  ```js
  {
    dailyBudget: number,           // งบรายวัน เริ่ม 500
    transactions: [{ id, type:'expense'|'income', cat, amount, ts }],
    goals: [{ id, title, color, target, saved, note }],
    streak: { count, lastDay }     // lastDay = 'YYYY-M-D'
  }
  ```
- **ค่าคำนวณ (derived)** — ทำใหม่ทุก render ไม่เก็บซ้ำ:
  - งบเหลือวันนี้ = `dailyBudget − ผลรวมรายจ่ายของวันนี้`
  - streak: ถ้าบันทึกวันนี้ครั้งแรก และวันล่าสุด=เมื่อวาน → +1, ไม่งั้นรีเซ็ตเป็น 1
  - สถิติเดือน/กราฟ 7 วัน/breakdown — กรองจาก transactions ตาม timestamp
  - badge/ระดับ — เงื่อนไขจากค่าจริง
- **Persistence**: ทุกการเปลี่ยน data เรียก `localStorage.setItem`; โหลดอ่านกลับตอน init

### Typography
- **ตัวเลข/เงิน**: `Space Grotesk` (400–700) — ใช้ class `.num` กับทุกจำนวนเงิน
- **ข้อความไทย/UI**: `IBM Plex Sans Thai` (300–700)
- สเกล: ตัวเลขฮีโร่ 54–58px/600 · หัวข้อหน้า 24px/700 · หัวการ์ด 15–16px/600 · เนื้อหา 14–15px · ป้ายย่อย 11–13px

- Radius: ปุ่ม/ชิป `100px` (pill) · การ์ดใหญ่ `18–20px` · ไอคอนหมวด `13–16px` · ปุ่มแป้น `18px`
- Padding หน้า: `14px 22px` (ล่างเผื่อแท็บบาร์ + safe-area)
- เงา FAB: `0 10px 24px -6px color-mix(in srgb, var(--accent) 60%, transparent)`
- ใช้ `color-mix(in srgb, …)` หลายจุดสำหรับสีโปร่ง — ถ้า target ไม่รองรับ ให้ทำ rgba ล่วงหน้า

## PWA
- `manifest.webmanifest` — standalone, portrait, theme `#0B0B0C`, ไอคอน 192/512 (any maskable)
- meta: `apple-mobile-web-app-capable`, `viewport-fit=cover`, `apple-touch-icon`
- ติดตั้ง: เปิดในเบราว์เซอร์มือถือ → "เพิ่มไปยังหน้าจอโฮม" → เปิดเต็มจอเหมือนแอป
